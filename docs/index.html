NAME

Real-Fruit-Snacks - water-themed offensive security toolkit.

SYNOPSIS

git clone https://github.com/Real-Fruit-Snacks/Real-Fruit-Snacks.git

DESCRIPTION

Real-Fruit-Snacks is a personal offensive-security toolkit maintained as ~50 independent GitHub repositories under a single org umbrella. Every project is field-built for authorized red team engagements, pentests, and security research — not academic exercises.

The toolkit spans the full operator workflow: payload delivery, C2, post-exploitation, lateral movement, AD enumeration, credential abuse, and reference environments for the lab. Each tool ships standalone — no shared runtime, no monorepo lock-in. Pick what you need.

CATEGORIES

C2 & Post-Exploitation
OPSEC-first C2 frameworks like Kraken, Aquifer, Siphon, and Wellspring.
Network & Tunneling
Tools like Flux, Neap, and Slipstream for TLS+Noise encryption, port forwarding, and stealth routing.
Shells & Implants
Encrypted reverse shells and loaders in pure assembly (Vapor, Grotto, Undercurrent).
Enumeration & Exploitation
Active Directory audits, web fuzzing, credential spraying, and offensive forensics.
Multi-Call Binaries
A sail-themed sextet of single-binary shell toolkits in six different languages.
