NAME

Real-Fruit-Snacks - water-themed offensive security toolkit, and everything built along the way.

SYNOPSIS

git clone https://github.com/Real-Fruit-Snacks/Real-Fruit-Snacks.git

DESCRIPTION

Real-Fruit-Snacks is a collection of 100+ independent repositories. At its core is a personal offensive-security toolkit, field-built for authorized red team engagements, pentests, and security research — not academic exercises.

The toolkit spans the full operator workflow: payload delivery, C2, post-exploitation, lateral movement, AD enumeration, credential abuse, and privilege escalation. Around that core: offline reference sites, single-page command builders, Obsidian plugins, the Terminal Workbench theme family, and browser games. Each project ships standalone — no shared runtime, no monorepo lock-in. Pick what you need.

CATEGORIES

C2 & Post-Exploitation
OPSEC-first C2 and delivery: Kraken, Aquifer, Siphon, Wellspring, Spillway.
Network & Tunneling
Flux, Neap, Undertow, Slipstream, Conduit, Culvert, Depth, and xfer for encrypted channels, port forwarding, and pivoting.
Shells & Implants
Encrypted reverse shells and loaders in C and pure assembly (Vapor, Grotto, Dew, Droplet, Undercurrent).
Active Directory & Credentials
forge-framework, anvil, Runoff, Maelstrom, Rapids, Lure, and Abyss.
Enumeration & Privilege Escalation
Web fuzzing, scan parsing, and privesc reasoning (Flood, Seep, Whirlpool, Deluge).
Multi-Call Binaries
A sail-themed sextet of BusyBox-style toolkits in six languages.
Reference & Tools
Offline man and tldr pages, command builders, calculators, and desktop utilities. No servers, no accounts.
Obsidian
17 plugins and 5 themes.
Terminal Workbench
One theme spec ported to Obsidian, VS Code, Vim, Windows Terminal, Notepad++, and Brave.
Games
Chess trainer, roguelites, incrementals, and browser horror.
